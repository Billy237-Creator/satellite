# Satellite Image Comparison
This project is a Java program that compares two satellite images represented by matrices of pixel values.
The program determines the smallest bounding rectangle containing all differences between the old image and the new image.
## Requirements

- Java JDK 21 or later
- Command Prompt or another terminal

## Project Files

- `Main.java` - Java source code
- `test1.txt` - Test with identical images
- `test2.txt` - Test with a single different pixel
- `test3.txt` - Test with multiple differences
- `Satellite_Report.docx` - Assignment report with explanations and test results

## Compilation

Compile the Java program with:

```bash
javac Main.java
